# 前端工程

> 前端工程化面试方向，涵盖 React/Vue、微前端、性能优化与工程化体系

## 基本信息

- **方向名称**: 前端工程
- **描述**: 前端工程化面试方向，涵盖 React/Vue、微前端、性能优化与工程化体系
- **版本**: 1.0.0

## 考察范围

- JavaScript/TypeScript 核心
- React/Vue 框架深度
- 前端工程化（Webpack/Vite）
- 浏览器渲染原理与性能优化
- 微前端架构（qiankun、Module Federation）
- Node.js 与服务端渲染
- 前端监控与埋点系统
- CSS 原子化与响应式布局
- 跨平台开发（React Native、Flutter）
- 前端安全与防御

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | JS/TS 基础、React/Vue 基础、工程化入门 |
| 中级 | 35% | 框架源码、性能优化、微前端实践 |
| 高级 | 25% | 跨端架构、监控体系、前端基建 |

## 参考知识库

- Virtual DOM 与 Diff 算法
- Webpack 构建优化策略
- 浏览器关键渲染路径
- 前端错误监控体系
- Module Federation 原理
- SSR 与服务端渲染优化
- 前端安全（XSS、CSRF）
