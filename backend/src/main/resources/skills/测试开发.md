# 测试开发

> 测试开发面试方向，涵盖自动化测试、性能测试与质量保障体系

## 基本信息

- **方向名称**: 测试开发
- **描述**: 测试开发面试方向，涵盖自动化测试、性能测试与质量保障体系
- **版本**: 1.0.0

## 考察范围

- 软件测试理论（黑盒/白盒/灰盒）
- 自动化测试框架（Selenium、Playwright）
- 接口测试（Postman、RestAssured）
- 性能测试（JMeter、Locust）
- 单元测试与 Mock（JUnit、Mockito）
- 持续集成与测试流水线
- 质量度量与缺陷分析
- 安全测试基础
- AI 在测试中的应用
- 测试工具开发（自定义平台）

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | 测试理论、用例设计、简单自动化 |
| 中级 | 35% | 框架搭建、CI 集成、性能测试分析 |
| 高级 | 25% | 测试平台开发、质量体系搭建、AI 测试 |

## 参考知识库

- 测试用例设计方法（等价类、边界值、正交）
- Page Object 设计模式
- 分层自动化测试策略
- 性能测试指标（TPS、RT、P90/P99）
- 全链路压测方案
- 代码覆盖率与增量覆盖
- 混沌工程与故障注入
