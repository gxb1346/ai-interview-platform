# 阿里后端

> 阿里后端专项面试方向，侧重阿里技术栈（Dubbo、Nacos、Sentinel、RocketMQ）与高并发架构

## 基本信息

- **方向名称**: 阿里后端
- **描述**: 阿里后端专项面试方向，侧重阿里技术栈与高并发架构
- **版本**: 1.0.0

## 考察范围

- Java 基础与并发编程
- Spring 全家桶深度实践
- Dubbo/HSF 服务框架
- Nacos/Config 配置中心
- Sentinel 流量治理
- RocketMQ 消息中间件
- PolarDB/MySQL 数据库
- TDDL 分库分表
- 阿里云原生体系（K8s、Serverless）
- 高并发秒杀/大促系统架构

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | Java 基础、Spring 基础、Dubbo 入门 |
| 中级 | 35% | Dubbo 源码、Sentinel 规则、RocketMQ 事务消息 |
| 高级 | 25% | 大促高并发架构、全链路压测、容量规划 |

## 参考知识库

- Dubbo 服务暴露与引用原理
- Sentinel 滑动窗口限流算法
- RocketMQ 事务消息实现
- Nacos CP/AP 架构切换
- TDDL 分库分表策略
- 秒杀系统架构设计
- 全链路压测方案
- 阿里云 K8s 集群管理
