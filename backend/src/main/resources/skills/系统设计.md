# 系统设计

> 系统架构设计面试方向，涵盖分布式系统、高可用高并发架构设计

## 基本信息

- **方向名称**: 系统设计
- **描述**: 系统架构设计面试方向，涵盖分布式系统、高可用高并发架构设计
- **版本**: 1.0.0

## 考察范围

- 分布式系统基础理论
- 微服务拆分与治理
- 高可用架构（冗余、故障转移）
- 高并发设计（读写分离、CQRS）
- 数据存储设计（SQL vs NoSQL）
- 缓存架构（多级缓存、缓存策略）
- 消息队列与事件驱动
- 分布式 ID 生成与一致性
- 大型系统案例（设计微博/微信/电商）
- 可观测性（监控、日志、链路追踪）

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | 系统设计基础概念、单机架构设计 |
| 中级 | 35% | 分布式组件选型、中型系统设计 |
| 高级 | 25% | 海量系统设计、容灾架构、成本优化 |

## 参考知识库

- CAP 理论与 BASE 实践
- 一致性哈希与数据分片
- 分布式事务（2PC、TCC、Saga）
- 熔断降级与限流（Sentinel、Hystrix）
- 多级缓存架构（本地+分布式+CDN）
- 分布式 ID 生成方案
- 链路追踪（Dapper、Zipkin）
- 异地多活与容灾
