- **方向名称**: 字节后端

## 考察范围

- Go/Java 双语言开发
- 微服务框架（Kitex/CloudWeGo）
- Redis 深度实践
- MySQL 与 ByteNDB
- Kafka 消息引擎
- RPC 框架与序列化
- 高并发推送/推荐系统
- 分布式存储（HDFS/ByteStore）
- 容器化与 K8s（TCE）
- AB 测试与数据驱动开发
