# 算法与数据结构

> 算法面试方向，涵盖常见算法、数据结构与海量数据处理

## 基本信息

- **方向名称**: 算法与数据结构
- **描述**: 算法面试方向，涵盖常见算法、数据结构与海量数据处理
- **版本**: 1.0.0

## 考察范围

- 数组、链表、栈、队列
- 树与图（BST、Trie、并查集）
- 动态规划与状态压缩
- 贪心算法与回溯
- 排序与搜索算法
- 字符串匹配（KMP、AC自动机）
- 设计数据结构（LRU、LFU）
- 海量数据处理（Bitmap、Bloom Filter）
- 并发算法与无锁数据结构
- 算法复杂度分析与优化

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | 基础数据结构与简单算法实现 |
| 中级 | 35% | 经典算法题与中等难度系统设计 |
| 高级 | 25% | 复杂优化方案与海量数据处理 |

## 参考知识库

- 排序算法时间复杂度对比
- 红黑树与 AVL 树对比
- 动态规划状态转移方程设计
- KMP 算法 next 数组构建
- LRU Cache 的 LinkedHashMap 实现
- Bitmap 在海量去重中的应用
- 分段锁与无锁并发数据结构
