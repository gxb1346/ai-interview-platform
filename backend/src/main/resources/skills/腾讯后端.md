# 腾讯后端

> 腾讯后端专项面试方向，侧重 TARS、IM 系统、海量服务架构

## 基本信息

- **方向名称**: 腾讯后端
- **描述**: 腾讯后端专项面试方向，侧重 TARS、IM 系统、海量服务架构
- **版本**: 1.0.0

## 考察范围

- C++/Go/Java 后端开发
- 腾讯微服务框架（TARS）
- 分布式存储（Ceph、HDFS）
- MySQL/TDSQL 数据库
- Redis/Memcached 缓存
- 消息队列（CMQ、CKafka）
- 游戏后端/社交后端架构
- 即时通讯（IM）系统设计
- 海量服务架构（QQ/微信级）
- CDN 与边缘计算

## 难度分布

| 等级 | 占比 | 说明 |
|------|------|------|
| 校招 | 40% | 编程语言基础、IM 基本概念、网络协议 |
| 中级 | 35% | TARS 框架实践、IM 系统模块、海量数据设计 |
| 高级 | 25% | 微信级架构设计、消息可靠性、容灾方案 |

## 参考知识库

- TARS 服务框架设计
- IM 消息模型（离线/在线/多端同步）
- 海量连接管理（C1000K）
- TDSQL 分布式数据库
- 消息必达与去重策略
- CDN 加速原理
